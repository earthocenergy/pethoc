# Pethoc

Pethoc is a lean LPG marketplace for nearby vendor ordering and fulfilment in Nigeria.

## Phase 0 architecture

- Next.js application
- Supabase Auth, PostgreSQL and Realtime
- GitHub as source of truth
- Vercel deployment

## Core portals

- Customer
- Vendor
- Admin

## Phase 0 scope

Customer ordering, vendor matching and fulfilment, Petwallet ledger foundation, admin operations, vendor onboarding, order history, and realtime status updates.

This repository replaces Floot as the primary development source for the Pethoc Phase 0 migration.
